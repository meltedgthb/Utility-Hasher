# Utility Hasher

Ever had a little brother sneak into your room and get your files? Well, this changes all that!
The Utility Hasher has many uses. It can hash these file types:

ZIP, MP3, WAV, TXT, MD, PY, JS, PS1, TAR, 7Z, ect.

It can hash many things. But how? Simple! (This requires Python >=3.13)

Step 1: Download the ZIP (Code > Download as ZIP).
Step 2: Extract contents to the Desktop.
Step 3: Find Python file "site-hasher.py".
Step 4: Open the file with Notepad, not Python.
Step 5: Find "Nautilus.mp3" in the Python script.
Step 6: Replace "Nautilus.mp3" with whatever file you want to hash.
Step 7: Save your changes (Ctrl + S).
Step 8: Close Notepad.
Step 9: Open Command Prompt.
Step 10: Type:

cd \Desktop

or 

cd \OneDrive\Desktop

depending on if you use OneDrive.

Step 11: Run the .bat file.
Step 12: Copy the hash.
Step 13: Replace the file name and its text with the hash.

It's that easy!
